# FrameLedger · 影视制作预算与资产版权协同平台

React + Vite + TypeScript 前端，Node.js + Express + TypeScript 服务端。面向中型影视制作团队，演示预算版本、成本预测、合同里程碑、资产版本、授权窗口冲突与审批审计的协同闭环。

## 启动

```bash
npm install
npm run dev
```

前端默认 Vite 端口 5173，API 默认 `http://localhost:4104`。

## 业务能力

- 项目 / 季 / 交付日期与预算基线；计划、承诺、实际、预测成本四账合一
- 供应商合同额度、付款里程碑与付款暴露额
- 母版、预告、海报、音频、字幕等资产版本和 checksum 登记
- 地域、平台、有效期、版权标签冲突检测（同族替代版本不算双授权，仅生效资产参与）
- **统一锁定/换版/回退领域流程**（锁定不是状态翻转）：
  - **锁定**：`POST /api/assets/:id/lock-requests` 申请票据 → 审批通过 → `POST /api/lock-tickets/:id/commit` 提交。
    提交时重新加载资产并校验三重门禁：checksum 与登记台账一致且格式有效、必要审批已通过、授权窗口有效且无 critical 权利风险；
    pending 票据唯一、同资产提交串行互斥，重复/并发锁定只可能生效一次，失败不半写并写 `LOCK_REJECTED` 审计。
  - **换版**：只能对已锁定版本登记候选新版（携带 `supersedesId`，与旧版同族）；候选审批与门禁通过后原子替代，
    旧版标记 `superseded` 永久保留。预备交付包自动改指向新版；引用旧版的已交付交付包快照一行不动，须显式 `acknowledgeDeliveries` 确认。
  - **回退**：授权失效等应急场景沿 `supersedesId` 链回到族内历史版本（跨谱系/伪造目标拒绝）；
    目标同样过三重门禁（恢复生效也需审批）。当前版本标记 `revoked` 留史不删除，引用它的已交付交付包召回（recalled，快照保留），预备包改指向。
    任何失败都写 `ROLLBACK_FAILED` 审计且状态不半写。
  - `GET /api/projects/:id/consistency` 提供摘要/冲突/审批/资产/交付/票据六表对账，用于重载验证。
- 预算 / 资产 / 交付审批队列和审计事件
- React 控制台支持项目切换、预算表、风险雷达、审批操作、版权资产视图与锁定/换版/回退操作

当前使用内存数据，领域服务按模块设计，后续可替换 PostgreSQL、对象存储、工作流和版权方台账服务。
测试：`npm test`（覆盖门禁三要素、重复/并发锁定、请求中风险变化、换版谱系与交付引用、回退失败不半写与成功召回、每步重载一致性）。
